# Kalki-Kit
AI-Powered Fake News Detection & Fact Verification Platform
# Project Description
Kalki-Kit is an AI-powered misinformation detection platform designed to identify and verify fake news using a structured offline knowledge base and intelligent claim-matching algorithms. It provides explainable verification reports, confidence scores, evidence, and awareness posters to help users make informed decisions before sharing information.
# Problem Statement
The rapid spread of fake news on social media has become a major challenge, leading to misinformation, public confusion, financial losses, and societal harm. Existing verification methods often require internet access or expert intervention. Kalki-Kit offers a fast, accessible, and explainable fact-checking solution.
# Objectives
- Verify the authenticity of news claims.
Detect misinformation using a structured knowledge base.
Generate confidence scores and risk levels.
Provide evidence-based explanations.
Promote digital literacy through awareness posters.
Support responsible information sharing.

# Dataset
A structured offline dataset containing verified claims across multiple domains, including Science, Health, Technology, Geography, History, Environment, Space, Cyber Security, Sports, and General Knowledge. Each record includes the claim, keywords, verdict, confidence score, evidence, trusted source, and explanation.
